# Admin maintenance, manual actions and images

Inventory maintenance is checked every two seconds and after owned-egg updates, without waiting for a new field cycle. Collection of an eligible field egg always preempts uncommitted maintenance. Inventory operations remain serialized; pending remote requests must settle before another action or teleport.

Placement samples real unobstructed rays from several directions on the owned PetArea. Occupied positions and actual ray blockers remain excluded. The game still validates each PlantEgg request. Automatic hatching uses the same live-record countdown as Render and manual hatching, including ReadyAt and current night credit. Only eggs awaiting their own eligible mutation are held back. A failed Equip Best attempt no longer blocks fusion; Equip Best is retried on inventory changes rather than once per field cycle.

Manual commands can be requested while AUTO remains ON. They wait up to 30 seconds for a boundary with no flight, carried egg or eligible field target, temporarily reserve the worker, leave the treadmill and resume the existing AUTO mode afterward. The command is rejected without dispatch if priority work persists. Sales/opening/mutations/fusion still revalidate ownership and current state. Uncommitted manual fusion movement yields to a new target; already committed requests finish confirmation.

`AutoSellAnimals` defaults OFF with its own `AutoSellAnimalsMin` and `AutoSellAnimalsMax` (inclusive). It sells only decoded backpack inventory animals in that income range. Equipped/pen animals, locked, favorite and fusion-slot animals are excluded. At most 64 are sent per batch. IDs are reserved before the native SellSelection event; uncertain batches are not resent automatically. Egg sales have the same no-resend reservation and report their confirmation/waiting status in Admin.

AdminRuntime coalesces owned-inventory changes into snapshots after 0.5 seconds, retaining its periodic fallback. Owned cards carry the current catalogue's egg and animal image IDs. Admin > Images > `images.collect` reads the current Data.Assets directory, including entries absent from Render's older static catalogue. It is a read-only command and can run with AUTO ON. Only positive numeric Roblox asset IDs are accepted. After validating the entire snapshot, Render registers the aliases and resolves thumbnails through the fixed Roblox thumbnails service, allowing only HTTPS rbxcdn.com results. No arbitrary image URLs or code are accepted. The mapping is refreshed from Admin reports and can be collected again after a script restart.

Verification uses Render tests and isolated Studio mocks (`tests/AdminMutations.spec.lua` and `tests/AdminMaintenance.spec.lua`). No live game inventory is sold, fused, opened or mutated by those tests.
